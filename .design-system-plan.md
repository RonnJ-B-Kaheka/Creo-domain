# Unified Design System Implementation Plan

## Objective
Ensure all main pages (Index, Service, Portfolio, Feature, Contact) follow the same high-energy brutalist design with consistent:
- Hero sections (different content, same style)
- Color scheme (Black bg, Pink/Cyan accents)
- Typography (Outfit font, bold uppercase)
- Layout patterns
- WOW features (cursor, grain, smooth scroll)

## Design Specifications

### Color Palette (Global)
- **Primary BG**: `#000000` (Pure Black)
- **Surface**: `#141414` (Dark Gray)
- **Accent 1**: `#FF0055` (Hot Pink)
- **Accent 2**: `#00E5FF` (Cyan)
- **Text Main**: `#FFFFFF` (White)
- **Text Muted**: `#888888` (Gray)

### Typography
- **Headings**: Outfit (900 weight, uppercase, tight letter-spacing)
- **Body**: Outfit (400-600 weight)
- **Hero Titles**: 8-12rem (responsive), outlined stroke effect

### Hero Pattern (All Pages)
```
- Full-screen height (90vh)
- Background image (blurred, low opacity)
- Gradient overlay (bottom to top)
- Centered content:
  - Mega title (outlined, glitch effect)
  - Subtitle (uppercase, spaced)
  - Description paragraph
  - 2 CTA buttons (primary clipped, secondary bordered)
  - Scroll indicator
```
